# 遠端指標 Remote Pointer

**線上報告時，聽眾想說「這張圖的這裡」，卻只能用嘴巴形容？**

讓聽眾直接移動報告者的游標；舉手、投票、+1 直接出現在簡報上，報告者不用跳出放映。

### [⬇ 下載最新版（Windows）](https://github.com/MichaelChou0806/remote-pointer/releases/latest/download/remote-pointer.exe)

不用安裝，點兩下就能用。聽眾用手機掃 QR code 即可，什麼都不用裝。

<sub>A Windows tool for Google Meet presentations: let the audience move the presenter's cursor, raise hands and vote right on the slides. The interface is in Traditional Chinese.</sub>

---

## 它解決什麼

| 以前 | 現在 |
|---|---|
| 「游標往左……不是，再上面一點」 | 聽眾按住一個鍵，自己把游標移過去 |
| 簡報一全螢幕，就看不到誰舉手 | 舉手直接出現在簡報角落，Meet 裡的舉手也看得到 |
| 想問大家意見，得跳出簡報開投票 | 大家用手機按 A／B／C／D，長條圖即時出現在簡報上 |
| 聽不懂，又不好意思打斷 | 匿名按一下「疑惑」，或用「+1」表示認同 |

## 三步開始

1. **報告者**：開程式 →「連線設定」取一個房間名稱和密碼 → 按「主持」→ 按「顯示加入用的 QR code」。
2. **聽眾**：手機掃 QR code，就能舉手、投票、按 +1。
3. **想幫忙指畫面的人**：也開這個程式，填同樣的房間名稱和密碼，按「操控」。

## 功能

- 🖱 **操控游標**：按住快速鍵並移動滑鼠，報告者的游標跟著動；也能幫忙翻頁。手機可以當遙控器。
- ✋ **舉手**：顯示先後名次，可以拿來搶答；展開後按骰子隨機抽一位。
- 📊 **即時投票**：A／B／C／D 與 ✓／✗，預設匿名，可以改票；結果自動存成圖片。
- 👍 **+1 與疑惑**：匿名，在報告者的螢幕上飄過。
- 🔗 **Google Meet 的舉手**：報告者的 Chrome 裝一次擴充功能，Meet 裡有人舉手也會顯示在簡報上。
- 🔄 **自動更新**：有新版會提示，按一下就完成。

## 常見問題

**Windows 顯示「已保護您的電腦」？**
按「其他資訊」→「仍要執行」。這個程式沒有購買數位簽章，第一次執行會被提醒。

**誰需要安裝？**
只有報告者，以及想用電腦操控游標的人。其他人用手機、平板或 Mac 的瀏覽器就可以。

**投票真的匿名嗎？**
是。不勾「記名投票」時，報告者只看得到票數；+1 和疑惑也不會顯示是誰按的。

**需要帳號嗎？**
不用。第一個按「主持」的人用自己取的密碼開房間，所有人離開後房間就消失。
